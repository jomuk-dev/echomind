# EchoMind

> Search your memories, not your folders.

---

## 🚀 About

EchoMind는 스마트폰의 사진을 AI가 이해하여 자연어로 검색할 수 있는 Personal Search Engine입니다.

예를 들어

- 민증 찾아줘
- 자동차 보험 보여줘
- 치과 영수증 찾아줘

처럼 검색할 수 있습니다.
